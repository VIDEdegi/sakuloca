# SakuLoca 1.1.0

写真に加え、ローカルの音声を言葉やファイル名で探せるようになりました。

- WAV（非圧縮PCM 16bit）・MP3・FLACを、30秒ごと・5秒重複の区間として解析・検索できます。mono/stereo、8〜96kHz、1ファイル24時間以内に対応します。
- 検索結果に時刻を表示し、再生時には前後5秒も含めます。検索で見つかった区間と実際の再生範囲を別々に表示し、前後の区間へも移動できます。
- 一般的な短い日本語の音名には、ローカルの同義語補助を適用します。適用した英語の音名を画面に表示します。自由な文章や否定文は置き換えません。
- 長いMP3・FLACは順番に区間をデコードし、録音全体をメモリへ展開しません。停止・再開、エラー確認、区間プレビュー、元ファイルを開く操作に対応します。
- ローカルMCP/CLIの音声検索・解析・形式フィルターに対応します。メディア本体やベクトルをMCPへ返しません。
- 写真の解析済みベクトルと設定を保持します。1.0.1からの初回起動時にDBを移行し、移行前バックアップを自動保存します。
- 画像ライブラリをPillow 13.0.0へ更新しました。Windowsのアプリ更新は署名済みのNSISセットアップを取得します。

音声検索はAIの類似度による候補検索です。すべての環境音や発話内容が上位になることを保証しません。日本語発話は人工音声での小規模評価までで、長い会話や騒音混在は追加評価の余地があります。前後を含めても音が続く場合は、隣の区間や元ファイルを開いて確認できます。

AAC/M4A・Ogg、文字起こし・話者特定・TTS・動画は対象外です。CPU/GPUは別の音声プロファイルとして扱います。以前の音声開発版からの更新後は、音声の差分解析を行ってください。写真の再解析は不要です。

更新前にSakuLocaを完全終了し、同じインストール先へセットアップしてください。元写真・元音声を編集・削除する機能はありません。確認環境はWindows 11 x64 / RTX 2070です。更新用署名とWindowsコード署名は異なり、Windows/SmartScreenの警告が表示される場合があります。
