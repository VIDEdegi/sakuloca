# SakuLoca 利用ガイド

SakuLoca 1.1.0の利用ガイドです。アプリ本体は無料・オープンソースで配布します。

1.1.0から写真に加えてWAV・MP3・FLACの音声検索を利用できます。

## インストールと初回設定

初期サポート対象はWindows 11 64bit、GPUの確認済み構成はRTX 2070（VRAM 8GB）です。他GPU、Windows 10、ARM/32bitは初期サポート対象外です。CPUは4スレッドの診断と少数人工画像の解析を確認しましたが、大量写真での実用速度は未評価です。モデルは約462 MiB、AIキャッシュ最大1 GiB、サムネイル最大512 MiB、検索データのために保存先に2 GiB以上の空きを推奨します。原写真の容量は別です。

NSISセットアップexeを起動し、インストール先を選びます。通常は管理者権限不要です。Python/Rust/Node/Visual Studioのインストールは不要で、Worker実行環境を同梱します。WebView2不足時はMicrosoft公式セットアップを利用します。オフラインの場合は[Microsoft公式WebView2配布](https://developer.microsoft.com/microsoft-edge/webview2/)からRuntimeを別途用意します。

初回画面でPC診断、モデル選択、保存先、写真フォルダー、背景設定、初回解析の順に案内します。途中で閉じても次回に同じ手順から再開できます。既存の登録フォルダーがある利用者には初回画面を強制しません。

既存の`.litertlm`はコピーせず参照して使えます。モデルがない場合は、容量・保存先・配布元・Apache-2.0条件を確認し、明示同意後に取得できます。Google公式ガイドが指定する[LiteRT Community配布](https://huggingface.co/litert-community/embeddinggemma-2-740m-litert-lm)の固定revisionを使用し、公開LFS SHA-256で検証します。取得は停止/再試行/途中再開できます。SHA不一致の途中ファイルは利用しません。異なる同名ファイルは上書きしません。オフラインでは既存ファイル指定を使用してください。

## 写真の登録と検索

「フォルダーを追加」で対象だけを登録します。サブフォルダーも対象で、JPEG/PNG/WebPを扱います。ドライブ全体や、保存先（モデル/検索データ）を含むフォルダーおよびその親・子にあたるフォルダーは登録できません。リンク/ジャンクションを追跡しません。登録解除は写真を消しませんが、そのフォルダーだけに所属する検索インデックスは除外します。

「差分更新 / 解析」で追加/変更された写真を解析します。同じモデルの保存済み写真を再解析しません。「海辺の風景」「赤いりんご」のような言葉や「画像で探す」で指定した参照画像で検索します。AIの類似度は正解率や確信度ではありません。細かな人物識別、文字の完全一致、撮影場所の断定は保証しません。ファイル名・形式・フォルダー・更新日で絞れ、意味検索以外は更新日/名前/サイズ順を選べます。フォルダー絞り込みの候補は有効なフォルダーだけです。検索語は直近8件をこのPCにだけ保持し、条件はまとめて解除できます。画像をドロップすると類似検索、フォルダーをドロップすると登録できます。

結果は30/60/120/200枚ごとのページで、ページ番号の入力、最初/最後のページへの移動ができます。意味検索は対象全体を近い順に並べ、1,001位以降もページで表示できます。同点は登録ID順です。フィルター変更時は該当写真全体から順位を計算します。グリッド/リストを切り替え、写真をクリックするとプレビュー、拡大/縮小（+/-/0）、前後の写真への移動（←/→）、元ファイル起動、Explorerでの選択、パスのコピーができます。Ctrl+Kで検索欄、F1でヘルプ、Escでダイアログ、Ctrl+Wでウィンドウを閉じます。Ctrl+Wも×と同じ背景設定に従います。ウィンドウのサイズと位置は次回起動時に復元します。元写真の編集・削除機能はありません。

## 音声の登録・検索・区間再生（1.1.0）

検索画面の「音声」に切り替え、音声のあるフォルダーを登録して「差分更新 / 解析」を押します。解析は選択中の写真/音声だけを対象にします。同じフォルダーに写真と音声が混在していても、それぞれの検索データを分けて保存します。

対応は**WAV（非圧縮PCM 16bit）・MP3・FLAC、mono/stereo、8〜96kHz、1ファイル24時間以内**です。AAC/M4A・Ogg、文字起こし、音声入力、話者識別、動画には対応していません。元の音声は読み取りだけで、形式変換や編集を保存しません。30秒ごと・5秒重複の区間として解析するため、長い音声の必要な時刻を探せます。全サンプルが完全にゼロの区間は言葉の検索から除外し、音量の小さな区間は残します。5秒より長い音や発話は境目で分かれることがあります。類似度の高い区間が音全体を含むとは限らないため、必要に応じて前後の区間や元ファイルも確認してください。

内容を説明する言葉で検索すると区間を類似順に並べます。名前・フォルダー・更新日などのフィルターも使えます。空の検索語では解析済み区間と無音区間を時刻付きで一覧表示します。結果をクリックすると前後5秒を含めて再生でき、検索で見つかった区間と再生範囲を別々に表示します。「前の区間」「次の区間」で同じ録音を時刻順にたどれます。プレーヤーの相対時刻とは別に元ファイルの位置も表示します。「元のファイル全体を開く」は関連アプリで全体を開き、「保存場所を開く」はExplorerを使います。

停止済み区間は保持して次回に未完了だけを再開します。音声のエラーは音声画面の件数、または音声を選択した状態の設定から確認し、修復後に再試行できます。CPU/GPUは別の音声プロファイルとして扱い、切り替え後はそのプロファイルの解析が必要です。音声開発版から更新した場合、差分更新時に新しい検索条件で音声を準備します。写真の既存プロファイルは保持します。公開サンプルを使った小規模評価では、音の種類や検索語によって順位に差がありました。一般的な短い日本語の音名は、同じ意味の英語を使って検索を補助し、適用した音名を画面に表示します。長い文章や否定文は置き換えません。類似度は正解率ではなく、話者や内容の正確な判定を保証しません。

初回の新Worker起動時にschema v1からv2へ移行し、写真のテーブル・ベクトルを維持します。移行前DBは同じ保存場所の `index.sqlite3.migration-<時刻>.bak` に保存して整合性を確認します。旧版は新schemaを開けないため、旧版へ戻す場合は完全終了後、現在のDBとWAL/SHMも退避した上で移行前バックアップのコピーを使ってください。元バックアップは残してください。

## 解析とバックグラウンド

背景実行は既定OFFです。OFF時のウィンドウの×は保存して完全終了します。ON時の×はトレイへ格納して、解析を継続します。GPU/CPU使用状況は画面下部とトレイのツールチップで確認できます。トレイからウィンドウ再表示、一時停止、差分解析/再開、完全終了を選べます。トレイメニューは実行中/停止中に合わせて一時停止・再開の有効状態を切り替えます。解析の完了・失敗はアプリ内通知で知らせ、実行状況はトレイのツールチップでも確認できます。

「一時停止」は処理中の1枚の保存後に止まり、保存済み結果は保持します。「完全終了」はWorkerを停止してアプリを終了します。解析中に完全終了する場合は確認を表示します。異常終了時は次回に未完了だけを再開できます。再起動後の自動再開は設定で明示許可した場合だけです。Windowsログイン時の起動も既定OFFです。背景実行を許可した場合にウィンドウを表示せず起動できます。

通常モードは既存の少数先読みを使います。低負荷モードは写真の間に待機時間を設けます。アイドル限定はWindowsで120秒操作がないときに次の写真を処理します。処理中の1枚は中断しません。差分自動更新は設定した間隔（最低5分）で対象を再走査します。GPU負荷の動的測定や別アプリ優先度制御は未実装です。

## 保存場所と容量

設定でモデル、本体SQLite、サムネイル、AIキャッシュ、空き容量を分けて確認できます。AIキャッシュ削除は次回のモデル読み込みを遅くしますが、モデル/検索ベクトル/写真は保持します。サムネイルだけを削除して次回表示時に再生成させることもできます。AIキャッシュ1 GiB、サムネイル512 MiB上限を維持します。

保存先変更は解析/取得を停止してから空の移行先を選びます。その下のLocalPhotoSearchDataへコピーし、SQLite整合性・ファイルのSHA-256を確認した後に保存先設定を切り替えて終了します。次回起動で新しい領域を使います。元領域は残します。失敗時も元を削除しません。再生成可能なAIキャッシュはコピーしないため、移行後の初回AI処理で作り直します。WebView2の一時表示データは移行後に再生成し、表示テーマは再設定が必要になる場合があります。環境変数MEDIA_SEARCH_DATA指定の起動では保存先を変更できません。

モデルだけ別の場所へ移す場合はアプリ外でコピーし、「既存モデルを選択」で新しいファイルを指定します。同一内容なら既存ベクトルを再利用できます。異なるモデルは別プロファイルになり、解析が必要です。勝手に全件再解析しません。

## エラーと復旧

- モデルなし: 既存モデルを選択するか確認後に取得。
- GPU失敗: ドライバー/モデルを確認し、CPUへ変更して診断。別GPUの対応を保証しません。
- Worker停止: 設定のWorker再起動で復旧。保存済み検索データは残ります。
- 空き容量不足: 別保存先または容量確保後に再開。64 MiB未満で新しい解析ジョブを開始しません。
- 未接続: 外付け/ネットワークドライブを再接続して差分更新。接続失敗で既存ベクトルを消しません。
- 壊れた画像/権限不足: エラー一覧で対象を確認し、権限や元画像を別途確認して再試行。パスはエラー一覧からコピーできます。画面下部のエラー件数を押すと一覧を開きます。

技術ログは設定から開けます。外部に自動送信しません。再起動時に直前のログを `worker.log.1` として残します。ログにはランタイムやローカルパスが含まれることがあるため、共有前に内容を確認してください。

## 手動更新とアンインストール

トレイの完全終了後に新しいセットアップを実行し、同じインストール先を選びます。設定・SQLite・モデルはアプリ本体と別に保持します。実行中のアプリがあれば更新/削除を拒否します。更新セットアップの起動に失敗した場合は解析Workerを自動で再起動します。その場合はアプリを完全終了し、同じセットアップを再実行してください。設定から署名付き更新を確認し、変更内容を見て取得・導入できます。起動時に更新があればモーダルではなく画面内の通知で知らせ、確認は無効化できます。Windows Authenticode署名はありません。

Windowsの設定からアンインストールできます。写真、検索データ、モデルは削除しません。ログイン起動の登録だけ解除します。v1.0.0の旧自動起動登録が残っている場合は、次回の自動起動設定の変更時にSakuLocaへ統合します。再インストールは保存先ポインターを再利用します。ユーザーデータ削除はアプリが勝手に行いません。必要なら保存場所を確認し、アプリ完全終了後に利用者が明示的に整理してください。

## プライバシーと外部通信

写真・検索文・ベクトルはローカル処理です。ローカルAPI待受ポートはなくstdin IPCです。外部通信は確認したモデル取得、Microsoft WebView2/Visual C++ Runtime導入、明示的に開いた公式ページです。写真/検索語の送信、広告、テレメトリーは実装していません。OS/ブラウザー/WebView2自体の通信は各提供元の設定に従います。

## Microsoft実行環境と不足時の復旧

アプリ本体はユーザー単位の導入です。Windows 10/11のUCRTを利用し、開発PCから収集したOS DLLを個別同梱しません。WorkerにはMicrosoft Visual C++ v14 x64（14.44以降）が必要です。不足時には確認後に[Microsoft公式パッケージ](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170)を取得し、Microsoft署名・x64製品・版を確認して公式導入画面を開きます。取得約25MiB、導入用約100MiBの空きを確保してください。共通Runtimeの導入には管理者確認が必要になる場合があります。アプリのためだけに開発ツールを導入する必要はありません。

失敗したら再試行または公式VC_redist.x64.exeを別途導入し、アプリのセットアップを再実行できます。Microsoft Runtimeが再起動を要求した場合は作業を保存して手動再起動後に再実行します。勝手にPCを再起動しません。アンインストールで共通Microsoft Runtimeを削除しません。

WebView2の公式小型Bootstrapperはアプリのセットアップに同梱します。Runtime本体の取得には通信が必要です。オフラインでは公式x64 Standalone Installerで準備して再実行してください。クリーンPC試験、Runtime不足時の実導入画面、実ログイン/スリープ/再起動は未完了です。

WebView2 RuntimeにはMicrosoftの独自利用条件があります。インストーラーの同意画面と `licenses/native/WebView2/RUNTIME_EULA.html` に公式全文を収録しています。SDKのBSDライセンスとは別です。WebView2にはMicrosoft Defender SmartScreenが含まれ、Microsoftの[プライバシー声明](https://aka.ms/privacy)と[Edge Privacy Whitepaper](https://learn.microsoft.com/en-us/microsoft-edge/privacy-whitepaper#smartscreen)で説明される利用者情報を収集・Microsoftへ送信する場合があります。Runtimeの診断・自動更新通信を、アプリ自身による写真・検索語の外部送信と混同しないでください。
